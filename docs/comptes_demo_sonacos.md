## Parcours recommande pour la soutenance

### Visiteur
- Ouvrir l'accueil
- Consulter le catalogue
- Ouvrir une fiche produit
- Aller vers connexion / inscription

### Client
- Se connecter avec `client@sonacos.ma`
- Ouvrir panier, commandes et factures
- Telecharger une facture

### Gestionnaire
- Ouvrir produits, stock, commandes, paiements
- Modifier un statut de commande
- Confirmer un paiement
- Enregistrer un mouvement de stock

### Responsable
- Ouvrir les demandes en attente
- Examiner une demande
- Valider ou refuser avec motif

### Administrateur
- Ouvrir gestion des utilisateurs
- Modifier un compte
- Activer / desactiver un compte
- Attribuer / retirer des roles

### Archiviste
- Ouvrir documents
- Consulter une facture
- Telecharger
- Archiver un document

### Auditeur
- Ouvrir le journal d'audit
- Filtrer
- Ouvrir le detail d'une operation
- Consulter commandes / stock / validations en lecture seule
